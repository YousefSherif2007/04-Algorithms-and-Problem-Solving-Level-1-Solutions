# Algorithms & Problem-Solving – Level 1 (Solutions)

My C++ solutions for the **Algorithms & Problem-Solving – Level 1** course by **Dr. Mohamed Abu-Hadhoud** on [Programming Advices](https://programmingadvices.com).

## About the Course
This course contains **50 problems**. In the previous course ([02-Algorithms-and-Problem-Solving-Level-1](https://github.com/YousefSherif2007/02-Algorithms-and-Problem-Solving-Level-1)), I solved these problems using a basic, step-by-step algorithmic approach.

In this course, I solved the **same 50 problems again using functions and procedures**, to write cleaner, reusable, and better-organized code.

## What I Practiced
- Breaking a problem into smaller, reusable functions
- Writing functions and procedures in C++
- Passing parameters and returning values
- Comparing a beginner-style solution with a structured one
- Testing and debugging my solutions
